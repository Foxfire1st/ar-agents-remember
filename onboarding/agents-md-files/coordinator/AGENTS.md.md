## Purpose

Canonical global coordinator instructions for role routing, managed-repository entry, memory resolution and gated transactions.

## Code Commentary

A product-started role follows its handover; the free-chat routing section addresses developer-facing sessions. For managed work the free chat records the request in the sprint, starts an Architect without a document argument, and points the developer to the dashboard. Another role is started only when the developer names that role and task. The first-sprint bootstrap supplies durable scope without creating global Architect identity.

The file routes repository and memory reads through the resolver and repository-specific system files. Before the build decision it uses read_ar_files to name source/card paths, then native tools read them. Its historical provider/retrieval names do not establish that those tools are exposed in a particular serving build. Code changes require the Architect plan gate; task-plan changes and transactions keep their explicit authority boundaries. The kept w-02 workflow owns closeout and landing procedures.
