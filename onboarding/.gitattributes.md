# .gitattributes

## Governing Overview

[agents-remember onboarding overview](overview.md)

## Purpose

The repository's Git attributes. It holds three entries, each with a comment that gives its reason:
a whitespace exemption for generated dashboard chunks, a binary mark for the vendored tiktoken
vocabulary, and the union merge of the two test catalogs.

## Code Commentary

- `mcp/src/agents_remember/package_data/dashboard/assets/*.js whitespace=-blank-at-eol`: generated
  Vite chunks can hold whitespace-only lines inside JavaScript template literals, so Git's
  trailing-whitespace check is switched off for them.
- `mcp/src/agents_remember/package_data/tiktoken/<file> -text`: the vendored vocabulary is checked
  by its SHA-256 before it is loaded. A line-ending conversion would change its bytes, so the file
  is marked as not text. The entry names the file by its exact name and is renamed by hand when the
  vocabulary is refreshed. The comment states that no test checks that the entry names the shipped
  file.
- `mcp/tests/test-evidence-lanes.toml merge=union` and
  `mcp/tests/evidence-lifecycle.toml merge=union`: Git merges these two files by keeping the lines
  that both sides added, instead of reporting a conflict.

### The union merge of the two test catalogs

Almost every change that adds a test file adds lines to these two catalogs. With `merge=union`, two
changes that add lines to the same list merge without a conflict. Git reads the attribute from the
worktree, for `git merge` and for `git stash apply` alike; the sync of a leaf reapplies the leaf's
parked work with `git stash apply`.

A union merge can leave a line twice, leave a list out of order, or bring back a line that one side
deleted. Both catalog loaders refuse a duplicate, an unordered list and the line of a file that no
longer exists, and they name the command that repairs it:

```text
python -m agents_remember_test_support.testing.evidence_lifecycle --project-root . --write
```

The comment above the two entries names these three results and the command. A union merge can
also interleave two whole rows that two changes added at the same place, which leaves a file that
does not parse; both loaders, the command and the start of a test run then say so and give the
recovery.

The attribute is set for these two paths only. `mcp/tests/test_evidence_catalog_canonical_form.py`
asks Git for the attribute of both paths and drives real merges and stash applications with it.
