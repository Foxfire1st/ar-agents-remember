## Purpose

The user guide for opening a bound review, asking the explainer for a recorded or planned explanation, and reading its retained page.

## Code Commentary

The explainer reads the copied task and requirement packets and reads the selected leaf’s reports in place through the path and SHA-256 inventory. It produces six private stage files, completes the evidence-bearing essay, and adds useful visuals before assembling the page. The rendered asset input is `drafts/assets/`. Claim checking also uses the admitted `instructions/evidence.json`.

The guide describes the planned form’s empty request for the requirement and planned effects. The Build route now carries that selected history to the service that composes the first turn.

## Evidence

- The guide describes the planned first-request wording and staged plan. The Build handler carries the dashboard’s history to the existing planned request composer. [2]
