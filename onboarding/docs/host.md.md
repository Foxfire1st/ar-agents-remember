## Purpose

Explains how Agents Remember runs with Paseo and how to select a host provider for a role agent.

## Code Commentary

The Antigravity section directs role starts to the ACP provider. A fresh native Antigravity start is refused before workspace preparation. A saved native Retry can reconcile the recorded agent. If that agent is absent, the bridge refuses before it can create a replacement.

The guide identifies Paseo 0.16.2 adapter source for standard I/O task-server forwarding. The installed witness ran on AR 3.0.3, Paseo 0.15.4 and Default mode. It verified the seat's own task server and delivered a role message. Auto behavior was unmeasured.
