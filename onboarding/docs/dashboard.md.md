## Purpose

Explains how to use the dashboard and the scope of its controls.

## Code Commentary

The launcher guide distinguishes available model inventory from options for the shown model. The pane can reuse a pair's options through a post-Start reread. Refresh clears those answers and renews the provider snapshot before the shown pair is queried again.

A matching saved model list stays selectable when fresh inventory is unavailable or loading. An eligible new Start preserves the selection and omits explicit feature overrides while shown-model options are unavailable or pending. Retry uses the saved request.

## Evidence

- The guide describes ordered Refresh, selectable saved inventory, and the separate treatment of feature overrides on Start and Retry. [1]
- The pane waits for current metadata, caches each shown pair, and sends feature overrides on new Start only with fresh options. [2]

- The dashboard guide identifies controls by their visible labels or accessible names and explains role starts, chats, tasks and repository knowledge. [4]
