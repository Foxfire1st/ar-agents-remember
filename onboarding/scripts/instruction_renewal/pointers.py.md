# scripts/instruction_renewal/pointers.py

## Governing Overview

[Overview](../../overview.md)

## Purpose

Renews pointer-action wording under authored action admissions and routing exceptions.

## Code Commentary

Policy identities are checked before pointer sentences are matched outside fenced blocks. Matching can use held wording, an explicit binding or a single unambiguous residual sentence. An ambiguous choice requires input. Generated rows are sorted current wording facts; they do not grant new action admissions or routing exceptions.

## Relationships

The authored pointer-actions policy owns admissions and exceptional grouping. The CLI accepts explicit pointer bindings and the planner writes the derived wording carrier.

- Authored policy identities are validated before current pointer matching. [1]
- Pointer matching uses wording, explicit bindings or an unambiguous residual candidate. [2]
