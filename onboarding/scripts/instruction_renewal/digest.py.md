## Purpose

Renews measured source, evidence, digest-place and clause bindings for the authored core-unit map.

## Code Commentary

Unchanged passages can relocate through unique exact hash windows. Changed or ambiguous passages require an explicit binding for the particular unit, evidence association, place or clause; a binding for one association does not authorize another. Clauses must remain within their place. The planner derives current hashes, headings, ranges, sizes and digest audiences while preserving authored unit membership and reference audiences.

## Relationships

The CLI supplies explicit unit bindings. The joined map composes authored and derived views for consumers; missing semantic decisions remain authoring work.
