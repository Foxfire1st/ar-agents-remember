## Purpose and current source account

Start checks record ownership, foreign ports and inherited daemon environment before bring-up; already-running returns before the root check. Stop addresses proven processes, and unrecorded ones are reported rather than signalled. Failed-start undo handles only this run's processes and keeps unresolved runtime records. Reset stops first, preserves a resetting marker through incomplete deletion and refuses unowned directories.
