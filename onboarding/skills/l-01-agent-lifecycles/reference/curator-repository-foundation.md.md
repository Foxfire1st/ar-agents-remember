## Purpose

Defines repository knowledge foundation as admitted task work carried by the existing Curator.

## Code Commentary

Setup reports the declared memory state; a user-started Architect opens the real foundation task and enclosure. The Curator receives the repository, scope and source bindings and uses c-14-knowledge-bootstrap. The procedure needs no incidental source delta, creates no onboarding, and reports unreached foundation scope. A missing task is reported instead of manufacturing a worktree or admission.
