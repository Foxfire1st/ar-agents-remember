## Purpose

Explains how roles combine attributed repository knowledge with direct code inspection at their working step.

## Code Commentary

Reads use the selected memory/code pair and exact inspected tree. Callers enumerate continuation pages, then open the named records, sibling realizations, proofs, code and tests. Recorded proofs describe test coverage, not a fresh passing run. Architect, Investigator, Worker and Reviewer sections apply this retrieval to diagnosis, editing, failures and complete-diff review without expanding sibling edit scope.

## Evidence

- Shared retrieval uses the selected pair, complete paging and native reads, and states gaps explicitly. [1]
- Role-specific use connects attribution with diagnosis and source inspection without filtering the complete diff. [2]
