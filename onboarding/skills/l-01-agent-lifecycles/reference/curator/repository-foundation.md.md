## Purpose

Defines a repository's first or resumed knowledge foundation as admitted task work carried by the existing Curator; this route authors knowledge and has no onboarding-authoring duty.

## Code Commentary

Setup reports the declared foundation state and names the next step through the Bootstrap foundation-state detail; the user-started Architect opens the real foundation task under a master and starts the Curator on that task document, and the Curator uses its actual enclosure contract. The Curator receives the repository identifier, resolved context, scope, sources and current knowledge state; no incidental code delta is required, and onboarding is optional input, never a start prerequisite. Authoring follows `c-14-knowledge-bootstrap` and creates no onboarding. An instructed session cannot replace task admission: a missing task is reported, and no task, worktree or enclosure is fabricated. Planning continues until the developer gives the commit instruction where he supplies it, and partial foundation scope is reported as partial with the areas not reached. The Curator role and the curation operation point here before a first or resumed foundation; the manifest also lists the Manager as a reader.
