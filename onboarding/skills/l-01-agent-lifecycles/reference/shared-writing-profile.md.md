## Purpose

Curators and explainer authors use this one selected STE-inspired profile: named actors, concrete verbs, one testable invariant promise, stable terminology, explicit conditions/exceptions and normally 20–25-word sentences with precision first. It claims neither full ASD-STE100 compliance nor a measured percentage.

The profile explains invariant, family/joint guarantee, realization, proof, history row, revision and candidate using existing term records. Keep identifiers, quoted sources and effect labels exact; missing, unexamined, unavailable and measured absence are not synonyms or equivalence evidence. Statement and semantic scope must remain connected; record support/provenance/mechanical fields retain their structural owners and producer inputs stay verbatim.

Before publication, independently compare old/new actor, trigger, required/forbidden behavior, quantifiers, conditions and exclusions against exact revisions/candidates. A non-author reader checks conforming, violating and boundary cases and records ambiguities/gaps. Clarify requires unchanged obligation; real changes use the existing effect/history/revision route. Examples are illustrations, not pilot evidence.

The pilot selects three real revisions: direct, conditional/exception-bearing and family-used. Use frozen originals and separate scratch-clone drafts, not official writes or rewritten history. After adoption later authored/revised statements, guarantees, reasons and walkthrough prose use the profile; migration procedures link it before waves. No automatic vocabulary/word-count semantic approval, new closeout gate, writer bypass or granted scratch-writer authorization is introduced.
