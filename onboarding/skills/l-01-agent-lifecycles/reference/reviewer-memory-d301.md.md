## Purpose

The independent memory reviewer reads quality-result landing cut-card and added-file reports. Removed text without a named task change and an added outside-knowledge file lacking a requirement place are findings. These are human review duties, not new automatic diagnostic refusals; a helper of the memory author cannot supply this independent check.
