## Purpose

The layout Curators copy for a repository's root onboarding overview.

## Code Commentary

A leading comment sends the Curator to the card-and-overview scope rules in `reference/curator/card-formats-and-citations.md`. Sections are What This Repo Is, Hot Path Summary, Architecture and Main Flows, Source Areas (area, source route, purpose, local overview link), Load-Bearing Files (source file, responsibility, card link), Contracts and Boundaries, Build and Development, Relationships and Documentation, Coverage and Open Questions, and an Evidence table of Finding | Anchor | Source.

## Evidence

- The root overview layout lists its sections from What This Repo Is to Evidence. [1]
- Source areas and load-bearing files are tables linking local overviews and cards. [2]
- The card-format reference points to the overview layouts before an overview is created. [3]
