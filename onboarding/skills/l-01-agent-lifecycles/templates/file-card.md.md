## Purpose

The layout Curators copy to write an onboarding card for one source file.

## Code Commentary

A leading comment sends the Curator to `reference/curator/card-formats-and-citations.md#choose-card-and-overview-scope` before filling it. The card has a source-path title and Governing Overview, Purpose, Code Commentary, Relationships and Evidence sections; Evidence is a Finding | Anchor | Source table whose source cell is `<source path>:<start>-<end>` and whose anchor is a defining symbol.

## Evidence

- The layout's sections are Governing Overview, Purpose, Code Commentary, Relationships and Evidence. [1]
- Evidence rows are Finding, Anchor and Source with a line range. [2]
- The card-format reference points to this layout before a source-file card is created. [3]
