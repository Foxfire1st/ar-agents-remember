## Purpose

Carries generated current source locations and wording for admitted pointer-action identities.

## Code Commentary

Each row connects an authored action identity to current source, fragment and wording facts. These rows are output of renewal rather than decisions about which action or exception is allowed. Consumers combine them with the authored policy.

## Relationships

The pointer planner produces this carrier. The authored pointer-actions policy remains the authority for admission and exceptional grouping.
