## Purpose

Retained shared authority corpus defining structural seat addresses, escalation and change ownership.

## Current Contract

The current source binds ordinary seats to canonical task selection plus role at role_start, while the Architect starts at Projects without a document. The caller of role_start is the started agent's parent; a dashboard or roleless-chat start has none. An identical request ID/selection reconciles one agent; a refused start has no alternative-tool fallback, and `role_start_set` is not the stage-start route: each stage starts its role with `role_start`. Harness helpers hold no AR seat or independent-review authority. Questions travel one rung to the actual parent, no role watches, polls or runs a timer loop, and the host's turn-end rules wake a silent Worker, Reviewer or Curator twice before marking the parent. Curation runs complete memory quality; authorized closeout carries that result without rerunning it and publishes only the approved code and prepared memory pair. The file also holds the shared rules for naming a sandbox run's host, plug-in and build versions, for removing scratch paths (no forced recursive removal through a shell variable; harness commands only in the supplied scratch roots) and for stopping a process or acting on the live host (only by a checked PID or the sandbox's PID file; dashboard rebuilds, host restarts and seat reloads only when the developer or the Architect assigns them); `core/every-role.md` delivers them to every role.

The agent that started a seat retires the agent in it with `retire_child`, and the tool refuses any other caller. A role's capsule ceiling is its entry in `current_capsule_ceilings_words` of `capsule-budgets-current.json`, with the developer decision that set it; the complete entry is read before the ceiling is stated, and only the developer sets or raises a ceiling.
