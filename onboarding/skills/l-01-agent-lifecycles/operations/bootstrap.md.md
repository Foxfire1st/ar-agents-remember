## Purpose

The new user's first hour, end to end, with the memory repository as its centre of gravity: what Agents Remember is for, the decisions only the developer can make, initializing the memory root, scaffolding the first onboarding, reaching the knowledge foundation, adopting the first attributed baseline, and verifying the result.

## Code Commentary

The carrier is a free agent, not a task seat: a session opens with `role=bootstrap` and no task document, and the compiled capsule reaches it as the session environment. It runs each step through the surface that owns it and points at the documenting `c-*` skill without restating procedure: resolved context first, the three developer decisions (foundation branch, new or existing memory repo, index now or defer), memory root init or repair, first onboarding scaffold, the knowledge-foundation read-and-report, first attributed baseline adoption, and indexing.

A brief, ticket, leaf document, worktree contract or gate is not an input here, and their absence is normal. The seat authors no records: the knowledge foundation is the curator's `c-14-knowledge-bootstrap` procedure, and this seat only reads and reports its state. Every claim in its report must be re-derivable from the named surface, previewed before applying and read back after.
