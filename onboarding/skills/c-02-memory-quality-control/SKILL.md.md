## Purpose

Canonical procedure for the Curator's complete contract-scoped memory-quality operation, drift diagnostics, onboarding maintenance routing and exact coherence authority. Package and harness copies are generated from this file; they hold no independent contract.

## Code Commentary

The skill distinguishes a successful diagnostic execution from a clean raw quality checklist. The Curator maintains affected cards, references, overviews, indexes and entities, runs the full operation, and repairs or explicitly escalates each actionable finding. A subset diagnostic is never full curation. Closeout consumes these results with its prepared Git inputs rather than rerunning curation.

The newly built converted contract requires source-bound onboarding rows: updated additionally requires counted prose or nonmechanical reference changes; source movement reopens the answer. Realization/proof-only changes do not count. This L53 rollout's own changed cards use the requirement's explicit pre-landing counted-change exception, not an invented no_impact statement or later backfill.

Validator reports have named route reasons. Sync-merge deferral and carried migration debt do not permanently exempt publication: new debt refuses immediately, complete migration makes carried debt refusing, and the five writer-reported rules refuse at commit/landing. The carried gone-path anchor is the refusing exception to generally reported content drift. The source's broader stale-reference sentence must be read with that explicit gone-path qualification.

Raw readiness precedes coherence. Preparation returns the complete candidate-set digest and file locations; the Curator reads that set before agent-owned judgments and publishes/validates exactly those identities. Neither clean structure nor coherence replaces semantic review or an independent non-author second reader before closeout.
