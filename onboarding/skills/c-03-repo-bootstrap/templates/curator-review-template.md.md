## Purpose

This template defines the curator review artifact used after route-overview or file-onboarding waves. It supplies review fields and checklist choices; the standalone template is not a completed review, a passing verdict, or a grant of acceptance authority.

## Code Commentary

### Logic

The curator review records repository and review-time metadata, the wave manifest, alternative review statuses, a summary, reviewed onboarding files and their source routes, compliance checks, reference-health issues, bucket corrections, required fixes, developer questions, and a next-wave recommendation.

### Conventions

The checklist covers route-local mirrored placement, strict one-to-one file onboarding, governing-overview backlinks and overview downlinks, separation from task-local planning, reference buckets and direct evidence, exclusion of registry and embedding proof, relative-path discipline, LOW-confidence handling, deferred files, and state updates. Its converted-card checks require no citation table left after the fixer and every numbered marker resolving to a sidecar reference. The checklist does not prescribe append-only card history; that narrow observation is not a general finding about history policy elsewhere.

### Invariants And Boundaries

The canonical bootstrap skill requires a curator review artifact after each overview or onboarding wave. Automated mode may remove phase-by-phase pauses after setup, but it does not remove evidence gates, curator reviews, state updates, or handoff. A review may identify required fixes rather than a pass. Its status choices, checklist examples, and recommendation placeholder do not demonstrate that any reviewed file or wave is complete.

### Historical Notes

The inherited note, “No file-local follow-up; reference anchors carry currentness,” is retained as a legacy note, not a fresh no-follow-up or currentness judgment. The current bootstrap rules require citation-table conversion and resolved sidecar references; review findings still depend on actual evidence, not an empty checklist.
