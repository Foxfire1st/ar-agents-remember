# dashboard/.gitignore

## Governing Overview

[repository overview](../overview.md)

## Purpose

Excludes the dashboard's machine-local dependencies, build outputs, development overrides and
browser-test artifacts from Git candidate content.

## Code Commentary

`node_modules/` keeps the worktree's dashboard dependency environment out of the untracked files
used by candidate accounting. A task installs it with the tool notes' command only when it builds
or tests the dashboard; other tasks install nothing there. The ignore rule is not an environment
installer, a cleanup instruction or evidence that a live Node environment was exercised.

`dist/`, local proxy overrides, TypeScript build caches, browser output and generated Panda trees
remain excluded for their existing owners. Candidate tests use their own worktree environment;
installed AR tools and memory-operation commands are still the landed product.

- The dashboard ignore rule excludes its Node dependency tree. [1]
- The accounting test rejects environment paths, but its Node half is structural when no Node tree is installed. [2]
