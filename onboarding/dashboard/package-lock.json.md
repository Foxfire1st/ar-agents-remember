# dashboard/package-lock.json

## Governing Overview

[repository overview](../overview.md)

## Purpose

The resolved dependency tree for `dashboard/package.json`, generated by npm. A reader uses it to check which Playwright version the checkout resolves, that the resolved tree is the one the manifest names, and which versions of the repository-document parser and sanitizer are resolved.

## Code Commentary

- The lock resolves `@playwright/test` 1.65.0, which depends on `playwright` 1.65.0, which depends on `playwright-core` 1.65.0. That is the same pair `canvas.explainer_browser` pins for the product's own fetch, and `mcp/tests/test_explainer_browser.py` fails when the two drift.
- The lock is a generated artifact: it changes when the manifest's version ranges resolve differently. It is not edited by hand, and it carries no product behaviour of its own beyond the resolution it records.

## Relationships

It is generated from `dashboard/package.json` and consumed by `npm ci` in the checkout. The browser test compares its Playwright version with the product's pin; the guide to the review page names the same version for a checkout's install of the browser.
