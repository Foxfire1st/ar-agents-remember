## Purpose

The suite exercises canonical hierarchy/bridge helpers with injected public SDK directories and native selection candidates.

## Code Commentary

Host mocks refuse limits above 200 and exercise continuation data, native activity and allowlisted labels. A background agent is included from both the subscribed page and a continuation page. Async Parent tests reject switched callers/relations, preserve split panes and handle roots/missing/archived targets. Replacement snapshots preserve newer and unrelated deltas, reject older loads and reconcile Parent pills. Explicit teardown removes the project listener, releases both directory subscriptions and clears all pills. Visible DOM candidates are intersected with current SDK IDs. The narrow fixture offers no Parent pill for an unknown source. The wide fixture removes the pill on loss of selection and restores it when the source becomes known again.

## Invariants And Boundaries

Injected failure and activity cases are source regression evidence, not independent live SDK transitions or actor creation.
