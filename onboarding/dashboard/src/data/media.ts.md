## Purpose

Shares supported media types, captions and bytes-route addresses across dashboard viewers.

## Code Commentary

The fixed suffix table covers PNG, JPEG, GIF, WebP, SVG, MP4 and WebM. Captions include the format label and available byte count. File, note and knowledge addresses retain their own repository and selection context. Change-set addresses preserve comparison, leaf, master or enclosure selectors, including supplied master generation pins.

## Relationships

MediaView draws the result. The server resolves and confines the selected bytes. Knowledge addresses carry the selected memory commit under the knowledge reader's separate selection contract.
