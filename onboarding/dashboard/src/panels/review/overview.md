## What This Area Is

The intent reviewer reads one leaf comparison as a page of changed intent and recorded source locations. Its navigation tree and reading column share one ordered change-set model. A named target selects its subject; an unnamed opening stays unselected. The page presents recorded facts and judgments without authoring knowledge or granting lifecycle approval.

## Hot Path Summary

Start at ReviewSurface for the question-bound read cycle, retained comparison frame and cache. reading/useReviewPage composes the shared model, selection, walk and scroll owners. changeSetOrder builds the pure model; tree/ReviewTree renders its compact navigation and reading/ReadingColumn renders its content. The shell supplies the task's retained chat column outside this route.

## Construction And Ownership

The opening reads summary, review context, outline/catalogue, leaf-wide trees, the shown subjects' cards and the lane. The shown invariant population controls card-read chunks. A requested older comparison carries its number through the relevant readers and is read-only. An unavailable measurement remains unavailable rather than becoming zero.

One sort orders both consumers. Changed retains real changes and selected or walked context; All exposes the catalogue. The tree-only filter matches family and subject identity/title/effect and location path/symbol/role. A multi-family invariant draws its locations at its first displayed occurrence. Entries sharing a recorded region draw one card and traversal stop while retaining distinct identities and entry-based counts.

The tree holds one-line family, subject, changed-location and counted group rows, then the pinned Worklist and Code without invariant navigation. The reading column holds full statements, recorded steps, changed cards, the two closed unchanged/not-comparable location groups and the inline code-without-invariant lane. Group rows reveal their reading-column group; they expand no code inside the tree. Raw identifiers, origins and comparison records belong in the closed Technical details fold after the content.

Code cards use one remembered Changes only/Full context choice. Their layout follows the measured reading content width: split at 1080 pixels and unified below. Full context is the recorded range; whole files open through the comparison viewer. The wording-diff layout control has its own retained owner.

blockIdentity supplies comparison-bound entry and hunk identities for selection, traversal, URL restoration and tray references. changeTraversal visits drawn changed blocks followed by lane hunks. Selection landing, tree-row reveal and settled reader-position retention have separate owners; their source mechanisms do not constitute new browser measurements.

## Invariants And Boundaries

The tree's height and contained scroller come from CSS. Hidden sidebars stay mounted and release their width; the shared SidebarToggle remains reachable. After the opening reads settle, an in-view lane file reads its classification and text without a gesture. Deferred file work remains limited to eight concurrent file tasks; card-mark work also waits for engagement. Pending reads retain page blocks and named failures occupy their requested slot. Catalogue completion chooses no subject, and no page or chat-column open starts an agent.

Server readers own immutable comparison operands, currentness, recorded effects, refusals and continuation cursors. Family context never substitutes for a selected subject's exact revision. Existing generated-page content remains an independently owned sandboxed slot; it does not replace deterministic review content.
