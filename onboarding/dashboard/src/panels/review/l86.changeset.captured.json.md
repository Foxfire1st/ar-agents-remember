## Purpose

The captured comparison change-set list of comparison 5: every changed code and memory file with status and counts, the echoed trees, and counters — the body the change-set page renders under each filter.

## Code Commentary

`GET /api/changeset/task?repo=…&leaf=260928-MIK-L37&comparison=5` (200, 64,428 bytes). `mode` is `comparison` with `comparison: 5`; `trees` echoes the four measured ids; `code` lists each file with status, insertions, deletions and `hasSidecar`; `memory` is scoped to the knowledge roots; `counters` sums both halves. Later disk edits never move these bytes.
