## Purpose

The captured catalogue answer of the recorded L37 review: every recorded subject with presence, totals, and the W03 navigation outline. It is the body the Changed/All tree renders from.

## Code Commentary

`GET /api/review/intent/entries?repo=agents-remember&master=260928_maintained-invariant-knowledge&leaf=260928-MIK-L37` (200, 48,895 bytes). `entries` lists each subject once with `selector_kind`, `selector_id`, label and `before_only`/`after_only`/`both` presence; `total_subjects`, `invariant_total` and `family_total` partition the catalogue. `outline` carries the full family/member/invariant tree with meaning changes, read from the two memory indexes only.
