## Purpose

The capture record for every l86 fixture: the producer command, the scratch world with its remapped L37 comparison 5, the selected tree rows, and each response's URL, hash and byte size.

## Code Commentary

`command` records the leaf-built producer over shared scratch clones. `fixture` records L37 comparison 5, repository-path remapping and the persisted 673-item worklist; selected family/member identify the opened capture rows. `responses` contains 12 named `l86.*.captured.json` fixtures and three separately retained raw `file-diff-responses` receipts, each with URL, status, SHA-256 and byte size. `aggregates` separately records the thirteenth named fixture, `l86.file-diffs.captured.json`, a JSON-parsed map of those three raw responses, not another HTTP response. `final_comparison_capture` qualifies only the refreshed changeset listing's producer boot.
