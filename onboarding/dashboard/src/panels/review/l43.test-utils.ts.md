## Governing Overview

[Owning route](../overview.md)

## Purpose

Load retained reviewer response bodies and provide the narrow fetch adapter used by the mounted meaning-effect tests.

## Code Commentary

Fixture paths resolve beside this module, so another checkout reads its own retained answers. Selection IDs come from each subject response’s first meaning record rather than a hand-maintained duplicate ID map. The adapter serves only the existing intent, intent/entries and trees routes, records requests, and throws for unknown paths.

Options substitute unavailable subjects, task replies, catalogue or tree replies to distinguish failure from valid empty answers. This is test-only transport replacement, not runtime fallback or a source of new product judgments.
