# dashboard/src/panels/detail-panel/directGrant.tsx

## Purpose

Selected subtask direct-grant presentation and scoped request state.

## Code Commentary

Only a planned subTask receives the shared switch; other granted stages show bare given-by words. Pending disables the control. Exact reference/key scopes Give/Revoke; refused writes keep the actual grant and selection turnover invalidates late replies. Served giver/time changes synchronize content. External grant mutation is not task JSON or browser authority.
