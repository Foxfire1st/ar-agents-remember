## Purpose

Provide explicitly invented DEV-only documents and response data exercising all task-reader blocks.

## Code Commentary

The exported rich document set contains a sprint, a master and tasks with enough statuses, progress, review, registers, decisions, references and graph edges to exercise the reader. Their text and approvals are made up. richApiAnswer answers only the developer demo's supported task-page requests from those invented documents.

A sample count or recorded-looking approval here is fixture data, not a real native review or developer decision. This rich demo differs from the genuine older-producer recordings used by recovery tests.

## Boundaries

No real task document is read or authored. These fixtures do not establish API producer fidelity, native findings, landing or independent browser acceptance.
