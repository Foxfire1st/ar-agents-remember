## Governing Overview

[Locked native conversation-library helper overview](overview.md)

## Purpose

Provides the deterministic repository-owned npm resolution graph for the private helper so runtime
behavior cannot depend on cache, OpenSrc, global-module, or `NODE_PATH` discovery.

## Code Commentary

### Logic

Lockfile version 3 records the root package's exact direct and development dependencies, resolved
tarballs/integrities, platform-specific optional packages, and the complete transitive graph.

### Conventions

This is intentionally large static dependency data. Update it only through reviewed npm lockfile
resolution after changing `package.json`; never hand-edit individual transitive rows.

### Invariants And Boundaries

- Root direct pins must remain Claude Agent SDK 0.3.207 and Pi Coding Agent 0.80.7 for this fixture
  cohort.
- Package integrities and resolved versions are reproducibility evidence, not native capability
  evidence.
- `node_modules/` remains generated/ignored and is never an onboarding subject.
