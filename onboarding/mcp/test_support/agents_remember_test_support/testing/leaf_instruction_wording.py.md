## Purpose

The module holds the per-role freedom and boundary clause tables, the leaf role/operation positive obligation tables and their normalized readers. The wording tests assert these clauses and remove each one to prove the guard fails; the module authors no knowledge itself.

## Code Commentary

The module is part of the leaf's direct hand-over and instruction-guard evidence. It holds no AR seat, starts no role, authors no knowledge and performs no boundary act; its tests run in the ordinary candidate population.

The Worker and coordination positive obligations now require the one `role_start_set` call on `agents-remember-task`, Worker opening and held Reviewer/Curator seats. Those literal obligations replace first-freeze Curator creation while preserving independent review and one Curator writer. Generated mirrors remain the public generator’s outputs.

## Current audience, delivery and evidence contract

`delivered_step` is now the common route for named-detail wording checks: it binds the selected role/operation through real admission and compilation, checks one exact source/step/byte reference, materializes launch files and verifies the recorded link and stored bytes. Reviewer and Curator alternatives are admitted only in their specific clause tables. Memory-review wording distinguishes the new recorded memory lane from untouched code state; these strings are not a semantic language gate.
