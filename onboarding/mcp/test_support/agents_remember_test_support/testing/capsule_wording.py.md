## Code Commentary

instruction_surface compiles the admitted capsule of the Worker, Reviewer or Curator seat that owns a declared leaf source (its role file or its operation) instead of concatenating unfiltered role/stage sources, and requires that seat's operation-route pointer sentences in both the role file and the compiled instructions; other sources are read directly. surface_clauses checks that the source is a declared leaf surface and returns its clauses unchanged, adding no alternatives. clause_mutations normalizes each facet, removes all accepted alternatives and yields the original/mutant for the consumer to assert; for upward notice recovery it also yields one mutant per required facet. assert_git_comparison_scope reads the same delivered file and tests presence/removal of the complete code-plus-two-memory-trees comparison sentence.
