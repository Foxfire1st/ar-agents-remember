## Purpose

Bind native review-summary dependency observations at dashboard composition, without moving selection authority into serving.

## Code Commentary

The port pairs initial selection observations with dependencies reported by native comparison resolution. Initial inputs include enclosure-directory selection, the recorded contract and applicable repositories/worktrees; absent paths remain observations. Invalid review context follows no invalid path. Resolved inputs include code/memory repositories, comparison records and database content. The callback observes native baseline captures; memoization here is scoped to a read, not global admission. ContentRead tracks database bytes rather than derived-index timestamps. This composition owns dependency wiring, not counts, path authority or an atomic workspace snapshot.
