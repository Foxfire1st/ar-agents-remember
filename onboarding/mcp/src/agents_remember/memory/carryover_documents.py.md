# mcp/src/agents_remember/memory/carryover_documents.py

## Governing Overview

[Memory area overview](overview.md)

## Purpose

Defines indivisible converted document units and official-tree anchor observations for carryover planning and apply.

## Code Commentary

### Format and path admission

Both roots must hold parsed layout markers with equal conversion versions. Unconverted inputs receive the central conversion refusal. Relative paths are validated; the memory root and every component of an admitted member path must not be symlinks, and an existing member must be a regular file. Sidecars must parse and match the mirrored card/route path.

### Pair and anchor completeness

A document is Markdown plus JSON; pair comparison names missing/differing bytes rather than silently selecting half a unit. Every realizes/proves anchor and every code/test reference anchor is observed at the opened official code tree. Zero anchors is not positive currentness evidence.

### Mechanical refresh and review

Apply rereads/reobserves units. Only current moved anchors whose content hash is unchanged are mapped through the writer API. Noncurrent anchors refuse unless explicitly reviewed, then remain unchanged for curator/validator judgment. Unmoved source bytes remain exact; moved sidecars use the canonical serializer. This helper writes no files/history.

### Memory-only selection

Automatic memory-only evidence requires at least one anchor, every anchor current and both target bytes unchanged since the resolved memory merge base; absent base or moved target requires review. Stable document selection distinguishes route coverage of landed paths, entity catalog and memory-only units.
