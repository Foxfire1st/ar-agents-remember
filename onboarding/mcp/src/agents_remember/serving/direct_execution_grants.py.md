## Purpose

Owns the dashboard developer route for the same shared leaf grants.

## Contract

DeveloperGrantRequest forbids extra fields and carries repository, canonical path and give/revoke action. The developer writer resolves a canonical subTask, proves unstartedness, preserves idempotent issuer/time and restores a removed grant when work starts during revocation. Started, ambiguous and wrong-kind cases refuse; the route returns the product's words and refreshes stored Markdown through the ordinary task store. It is not an agent-role grant API and adds no task-document field or shell-write protection.
