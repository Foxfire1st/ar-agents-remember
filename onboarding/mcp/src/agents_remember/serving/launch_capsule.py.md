## Purpose

Pure launch-instruction request/result vocabulary: exactly capsule or refused. Compilation and host launch admission live above this value module; no native-harness channel decision, legacy fallback, workspace rewrite or Eve binding helper remains here.

## Code Commentary

LAUNCH_OPERATION is orientation. LaunchCapsuleRequest holds role, workspace and optional canonical task reference; its explicit project-task flag permits the upper application owner to assess a real sprint/master binding without inventing a taskless identity. LaunchCapsule holds the generic delivery or named refusal, and is_refusal/explain report that outcome. refused_launch_capsule constructs the fail-closed value. This type does not decide which parentless roles may start and does not itself call the host.
