## Purpose

The generic frozen value carrying one admitted role capsule into a host role launch. It has no Codex app-server parameter builder, refresh planner, legacy switch or serialized carrier-artifact reader.

## Code Commentary

CapsuleBindingIdentity checks nonempty trimmed repository, task, role and operation fields and renders their report. CapsuleDelivery holds that identity, the trusted instruction stream and the compiler semantic digest, refusing blank instructions and a digest without the sha256: prefix. capsule_delivery_from structurally reads the compilation binding and admitted facts, maps role versus launcher seat, and copies render_instructions() plus the compiler digest without another compiler import or rerendering policy. No task/tool/model-authored field is a trusted-instruction input.
