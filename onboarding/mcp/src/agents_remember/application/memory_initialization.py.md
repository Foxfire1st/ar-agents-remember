## Governing Overview

[Area overview](overview.md)

## Purpose

Scaffolds a repository's memory root and reports the state of its knowledge foundation.

## Code Commentary

The initializer delegates scaffold creation to the kernel and measures knowledge through the same admission and dataset selection as bootstrap. A real successful scaffold change can refresh derived briefs from the selected code branch if the converted layout is present. Preview and no-change initialization skip that refresh. A derived refresh problem is included with the initialization result.

## Evidence

- Actual scaffold creation invokes the brief refresh and retains any resulting advisory. [1]
- Brief publication uses the initialized root and the selected code branch commit. [2]
- The knowledge measurement reports an unavailable, partial, recorded or empty foundation without authoring records. [3]
