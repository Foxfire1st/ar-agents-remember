## Purpose

Compile the internal capsule one role launch must carry, using the existing task-attached or manifest-routed compiler. The result is a generic delivery value; no vendor-specific Eve artifact or second native compiler path remains.

## Code Commentary

compile_launch_capsule canonicalizes role, refuses a role outside the capsule vocabulary, narrows operation and branches on an actual task reference. Task admission resolves canonical topology, registered repository and the task enclosure through WorktreeContractReader before compile_task_capsule. A no-enclosure project-task binding is separately constrained to real sprint/master roles at configured Projects scope. The taskless compilation primitive names absence as free-agent:<role>, derives altitude from the manifest and workspace identity/branch from actual Git facts, and digests admission rather than a nonexistent document. Both paths return capsule_delivery_from of the compiler result or a named refusal. Upper host-start admission remains the authority for which parentless roles may actually launch.
