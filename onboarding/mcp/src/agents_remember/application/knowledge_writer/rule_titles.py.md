## Governing Overview

[Area overview](../overview.md)

## Purpose

Validates the title on a producer entry or an invariant record request.

## Code Commentary

The record model limits a title to one line and 80 characters. A new rule requires a title. The writer can revise an existing untitled rule and report that readers use its first words until it has a name.

## Evidence

- A new rule needs a title and an existing untitled revision receives a note. [1]
