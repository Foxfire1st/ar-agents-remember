## Purpose

Derives immutable call-local MCP repository roots for an admitted canonical leaf reader request.

## Code Commentary

Without task_context readers retain configured Projects roots. With context, repository and canonical subTask must match: an enclosed leaf uses its exact canonical enclosure and one matching enclosure binding; a granted direct leaf uses its current readable grant and the exact master series contract. Configured admission and existing contract-owned roots remain mandatory. The enclosed branch returns before grant lookup. Caller supplies identities, never roots; a valid context for another leaf remains admissible and launch binding is not a second read-scope gate.
