## Purpose

Create an explicit successor from one named retained comparison and its original curator generation through the existing freeze and retention owners.

## Code Commentary

### Logic

The paired parent generation and curator digest are caller selections. The parent must reopen as the exact task-context generation with available retained operands and without an already captured assessment collection. The original curator record must match the parent's original source and repository line. A validated record bundle is passed to the shared resolved freeze with recorded parent lineage.

The operation never changes the parent, rewrites its judgments or installs a retained capture as a live identity. Conflicting live/absence inputs, foreign records, unavailable history and inexact parents refuse. The retention owner rechecks expected snapshot identities at copy; source or knowledge cannot be borrowed from the current branch.

### Conventions

Use the existing typed owners and exact recorded identities. Keep operation evidence and candidate provenance in task notes.

### Invariants And Boundaries

This is the explicit recovery entry, not a heuristic used when normal history lacks a pin. Existing generation publication, stage/pin reclamation and snapshot custody remain their existing owners.
