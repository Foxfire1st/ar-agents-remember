# mcp/src/agents_remember/package_data/runtime/providers/docker/codegraphcontext/patch_cgc.py

## Governing Overview

[CodeGraphContext requirements onboarding](../../requirements/codegraphcontext.txt.md)

## Purpose

`patch_cgc.py` is a package-owned Docker build asset for the managed
CodeGraphContext runner image. The Dockerfile copies and executes it inside the
image so Agents Remember patches — since L12 including the watcher timer-pop fix
(fired debounce timers leave the per-path dict) — are baked into the installed
`codegraphcontext` package instead of being generated by lifecycle Python at
runtime.

## Code Commentary

### Logic

The script locates the installed `codegraphcontext` package under Python
`purelib`, then walks a static list of patch operations. Each operation names a
package-relative file, acceptable original snippets, and the replacement text.
If the patched text already exists the operation is skipped; otherwise one
matching original snippet is replaced. A missing match raises `SystemExit` so
the Docker build fails instead of silently producing an unpatched runner image.

### Invariants And Boundaries

- Patch operations are static committed Docker build input; lifecycle code
  should not synthesize this script dynamically.
- The script must be idempotent for already-patched package files.
- Patch target drift is a build-time failure, not a runtime fallback path.
- The script mutates only files under the installed `codegraphcontext` package
  in the Docker image.
