## Purpose

The independent Reviewer examines one explicitly assigned seam or loop round, refutes or confirms each claim and supplies verdict evidence rather than decisions.

## Current Contract

Native intake uses exact task arguments, returned canonical path and actual reader schemas; each call carries its task/contract scope. Write only contained task-local review artifacts. Missing authority or capability is reported rather than substituted.

A baseline inspects the complete diff, including unattributed files, against the applicable standing catalog, three lenses and exact requirement evidence class. Knowledge mapping adds before/after family and unchanged-sibling examination. Preserve producer handoff fields for co-resolution.

Adjudicate each exact requirement revision/worker attempt separately, including declared knowledge effects against the packet; a rejected requirement blocks overall pass. Seal stable findings and observable repair criteria. Fix-verification covers only the preceding outstanding IDs without baseline reset, new findings or added scope; the three-round bound remains.

Keep task-bound attempt/verdict evidence, requested seam distinctions and owner-recorded review. Normal curation authoring remains the full-MQC exception; an explicit report-only curator admission cannot claim that pass complete.
