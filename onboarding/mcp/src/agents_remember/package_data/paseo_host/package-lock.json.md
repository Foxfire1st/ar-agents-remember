[overview](../../../../overview.md)

## Purpose

The complete npm lock of the host's package tree, so two installs of one build hold the same host package for package.

## Code Commentary

The provision installs from this lock and `installed_lock_matches` compares the installed prefix's lock bytes with it; release concordance checks its root dependency and the host package's entry against the contract.
