# Host-free turn-ended decision tests

[Governing plugin overview](../overview.md)

## Contract

Synthetic role facts, timelines and a controlled sender exercise silent-turn notifications without a host. Explicit returns suppress notices; busy parents, permission waits and running descendants defer them. Retry, overlap, restart and archive cases qualify held-line ownership and loss prevention. The size assertion checks the source constant, not settings reload. The contributed-handler case invokes the actual registerParentWakeEvents against a mock event registry and host sender, checks its five registered names, turn/permission gates and explicit steer option. This remains a synthetic composition, not live SDK callback payload, plugin-load or cross-harness wakeup proof.
