# Host-free turn-ended decision tests

[Governing plugin overview](../overview.md)

## Contract

Synthetic role facts, timelines and a controlled sender exercise silent-turn notifications without a host. Explicit returns suppress notices; busy parents, permission waits and running descendants defer them. Retry, overlap, restart and archive cases qualify held-line ownership and loss prevention. The size assertion checks the source constant, not settings reload. These tests do not establish native event registration, a live plugin load or cross-harness wakeup.

## Evidence

- The host-free suite checks bounded child/task/report lines, suppression, deferral, retry and restart behavior. [1]
