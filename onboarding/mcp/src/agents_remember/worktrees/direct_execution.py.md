## Purpose

Supplies an in-work direct leaf name to lower-layer integration refusal text.

## Contract

open_direct_leaf_name enumerates readable grants for the same repository/master, resolves canonical sibling documents, combines code/memory dirt with the exact leaf's completed direct-pair proof, and excludes the current leaf. Abandoned leaves and landed=True release first. A Completed leaf with start markers occupies only with checkout_dirty=True or landed=False; absent/unreadable/mismatched generation gives landed=None and uses the document/dirt fallback, not an invented incomplete pair. Non-Completed siblings use document start markers. When no leaf can be identified, the caller keeps its original refusal. This read-only naming helper does not replace the integration cleanliness gate or mutate grants.
