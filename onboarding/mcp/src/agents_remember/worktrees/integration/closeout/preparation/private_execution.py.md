## Governing Overview

[Owning overview](overview.md)

## Purpose

Map one retained write-enabled CloseoutPreparationIntent into its exact PrivateGitPreparationBinding; this residual mapper executes no private command or publication.

## Code Commentary

private_git_binding refuses an intent without writeEnabled, privateRoot or normalizedMessage, then copies its logical root/ref/expected-old commit, common directory, private root, parent/tree, message, policy spelling and operation/generation/intent identity into the existing binding type. Physical validation, capability admission and output inspection remain with their existing kernel owners; constructing this value proves none of them by itself.

The selected-leg create/materialize/commit executor, command retry/terminal logging and prepared-leg hook execution were removed. Retained historical source/journal evidence, including a missing original child exit, is not a new execution, successful retry or permission to replay. Ordinary/direct publication owns its current explicit checks; the residual policy field grants no bypass.
