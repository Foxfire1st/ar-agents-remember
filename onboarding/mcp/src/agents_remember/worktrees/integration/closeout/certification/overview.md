## What This Area Is

This area retains typed original terminal readback, terminal-selection construction and nested structured refusal. It no longer owns prepared-closeout candidate admission, suffix execution, memory/finalization continuation or recovery. Door/task authority, immutable storage and lifecycle journals remain separate surviving owners.

Source route: `mcp/src/agents_remember/worktrees/integration/closeout/certification/`.

## Hot Path Summary

Read `selection.py` for exact stored object type checks, original terminal publication/evidence verification and canonical-byte terminal selections; read `observation.py` for recursive finding projection and structured refusal.

## Construction And Ownership

`load_selected_terminal` follows explicit original references, including the original reused frozen run, verifies result and certificate publication authority and nested result evidence, and recompiles the exact planned gate result. `terminal_selection` retains original references and canonical publication bytes with SHA-256; it performs no journal CAS. `refuse` projects typed nested expected/observed evidence through the existing error boundary.

## Invariants And Boundaries

- Original typed evidence and publication remain mandatory; no latest-object search or provenance reconstruction substitutes for them.
- A selected certificate must bind a green result.
- The former complete selected graph, red retry/terminal replacement, prepared output normalization and default continuation were removed, not left unwired.
- Ordinary converted-memory gating and legacy-format cutover refusal survive outside this route.
- Source inspection is not production completion or execution evidence.
