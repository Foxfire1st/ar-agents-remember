## Governing Overview

[Integration overview](overview.md)

## Purpose

Censuses protected integration surfaces and rejects task-topology owners that collide or escape their canonical roots.

## Code Commentary

### Logic

It resolves repository sides, live leaves, sprint/series authority, document confinement, and protected workbench targets into exact collision findings.

The repository enclosure scan uses the shared notes/archive-excluding iterator. A parsed contract
whose task artifact resolves outside the positional repository tasks folder is not an in-scope
owner: it is skipped with a topology-collision warning naming its path before collision checks.
Unreadable contracts still fail at this boundary; a foreign identity inside an admitted member
enclosure still receives the existing identity and ownership checks.

### Conventions

Typed records and refusal payloads remain owned at the narrowest stable boundary. Callers consume
the public function or model instead of re-deriving its lower-level state machine.

### Invariants And Boundaries

- Each admitted member's protected surface has one canonical owner; document-confinement escape, foreign task identity, live-leaf ambiguity, or cross-series overlap fails closed. Positional task-document nonmembers are excluded from the census and named, not promoted into owners whose identity must be checked.
- Missing, unreadable, ambiguous, or conflicting authority fails loudly; this file does not add a
  fallback or compatibility shadow.
