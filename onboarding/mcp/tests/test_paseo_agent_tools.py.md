## Purpose and current source account

The suite checks the same-build tool definition and returned binding, a compact launch instruction, bounded regular handover artifacts, exclusive writers and exact retry refusal/reuse. New leaf launches use a real `role-reports` access folder and the canonical artifact path; retry restores a missing folder, refuses altered artifact bytes until deletion, and reuses the saved receipt/message without adding a link. Pre-existing alias receipts retain separate link-restoration and disagreement controls. The two storage generations are not interchangeable. These are dispatch/tool/artifact contracts, not proof that every provider uses the offered server correctly.
