- Ten equal uncovered B/C changes use the card-owning representative while preserving every source blob. The matching trace closes them, and later divergence reopens them. Different bases, independent cards and typed coverage are explicit non-grouping controls.
- Deleted routes trigger without history; a family reroute inside a linked directory triggers from its row. A family absent at base raises no route-condition item.
- A noncurrent refreshed reconsideration link stays open despite a stored row; actual currentness or restoring the base links closes it.
- Generated-copy facts are collected once; matching copies, including the binary fixture, do not raise an unexplained change, while the manual divergence does. This test source was read without opening protected real mirrors.
- Removed ordinary file/symbol/route links remain open after an owner row or revision; only removing or restating the actual target closes the item. Rename repair points to the destination, rather than waiving the missing old target.
- Unavailable recorded blobs are named in item facts, and a source file named overview that collides with the root card is refused by name.
- For changed invariants, moved/extended structural rows cannot hide the missing governing sentence; its reason precedes the missing-cover reason.
