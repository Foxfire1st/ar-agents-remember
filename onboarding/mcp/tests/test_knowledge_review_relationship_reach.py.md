## Code Commentary

Each shape the old line search used to follow past the union's page is built as a text tree and
read back through the production composition. No line is read past a withdrawn association's
citation: what the old reach displayed as a movement reads as a retraction stating what was
searched, and moved-to rows outside the union stay out — except where the candidate re-records
under a row the union holds, which pairs by that row. A member identities' moved realization is a
retraction with no read continuation; a two-sided movement names the recorded row it was paired on;
a row at a matching address with no recorded relation is only an addition. Rename inference
separates a measured absence from a measurement never made.

Test-only knowledge_rows_test_support family/revision/membership operations construct the input
populations. Real review composition supplies the rendered evidence and refusals; the cases do not
reinstate a retired authoring plane.
