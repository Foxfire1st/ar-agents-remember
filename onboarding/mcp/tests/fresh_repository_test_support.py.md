## Purpose

Build a real initialized and baseline-adopted memory pair for the first-knowledge journey.

## Code Commentary

`fresh_repository` opens the committed baseline as a leaf pair without an onboarding directory. It uses the initialization and baseline owners rather than substituting a hand-made memory layout. `author_first_card` runs after the empty-memory check and writes actual file and repository cards, then previews and applies their citations. The cards precede the first realization; they are content, not placeholders.
