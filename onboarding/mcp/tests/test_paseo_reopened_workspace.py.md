## Governing Overview

[Tests overview](overview.md)

## Purpose

Protect archived task workspace recovery through the real bridge script with a key-addressed controlled host, sharing the existing bridge-agent process fixture.

## Code Commentary

The cases distinguish visible archived replay, two archiving/archived generations with retry convergence, a completed old descriptor hidden by the live listing, exact traversal exhaustion and the final permitted live successor, and wrong successor/initial placement. Assertions check derived keys, returned identity and title, final-call created/found preparation, bounded create counts and absence of title mutation on refused or archived handles.

## Boundaries

These are controlled-host unit regressions, not a paid provider turn, native host retention test or post-landing start on an installation. Existing bridge-agent cases separately retain live-key and folder-only behavior. Lane and consumer declarations select the module but prove no invocation.

## Evidence

- A visible archived replay advances without titling the archive. [1]
- A hidden completed replay supplies its original identity for repeatable successor selection. [2]
- Archiving and archived generations derive identical keys on retry and report the final workspace found. [3]
- Nine archived candidates refuse with task/count; the last allowed live candidate still succeeds. [4]
- Invalid successor or initial placement stops before another continuation or workspace-title write. [5]
