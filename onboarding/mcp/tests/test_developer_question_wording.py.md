# mcp/tests/test_developer_question_wording.py

## Governing Overview

[tests route overview](overview.md)

## Purpose

Keeps the parent routing, the refusal recovery and the developer-answer provenance of the delivered R93 instruction texts, and proves each exact retired directive is independently detected.

## Code Commentary

The module reads the delivered canonical role and operation texts and requires the parent-routed question channel, what is held back and recommended, the busy and permission-prompt pending recovery under `**Pending developer questions**`, the unreachable-parent own-chat exception, the quoted developer-answer provenance and the permission notice with the permission name or "not supplied". A second test requires the leaf ownerRelation to name the parent, keep the sibling `roleMessageArguments` and drop the old result-to-parent order. The last test seeds each exact old directive alone — the Manager/Orchestrator forwarding prohibition, the SKILL own-chat sentence and the old SKILL coordinator exception — against its real current carrier and requires the retirement scanner to report it, with an undeclared architect carrier as the negative control.

## Evidence

- The parentable roles carry the question, recovery, provenance and notice clauses. [1]
- Every starter role carries the upward notice and unchanged downward answer duties. [2]
- The three operations keep conditional routing and pending recovery. [3]
- The leaf ownerRelation keeps peer results and named parent occasions. [4]
- Each exact retired directive is detected as an independent sentence. [5]
