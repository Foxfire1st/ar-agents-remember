# mcp/tests/test_missing_master_tool_answers.py

## Governing Overview

[tests overview](overview.md)

## Purpose

Refusals about a master reach the operator through the public tools with the repair named. A sprint that commands a master whose folder was archived by hand is answered by `curator_coherence` and `closeout_queue` with the master, the `0_archive` location and the retire operation; every other topology failure stays a bounded record. `task_doc.retire_master` names a series contract's worktree-group cell and the edit that clears it.

## Code Commentary

`_archive_by_hand` builds the archived master, `_queue` and `_coherence` read the public tool answers. The cases cover a text longer than the field, a master that goes missing between census and graph, and a recorded worktree group of another layout.

## Evidence

- A sprint that commands a master archived by hand is answered by curator_coherence and closeout_queue with the master, the archive location and the retire operation. [1]
- Every other topology failure stays a bounded record, and a recorded worktree group of another layout does not refuse a retirement. [2]
