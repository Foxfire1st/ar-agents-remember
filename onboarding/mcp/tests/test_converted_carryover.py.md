## Governing Overview

[Tests overview](overview.md)

## Purpose

Protect public converted carryover, complete review-detail delivery, format-first admission, noncommitting pair retries and recovery-leaf judgment before ordinary closeout.

## Code Commentary

The native fixture covers all document kinds, optional record companions and no copied source history. Full candidate pair/evidence/anchor/dependency/history, conversion and publication facts go to the whole-result log; delivered compact answers omit raw candidates/conversion/publication while carrying recovery guidance in next.summary and a log locator. Carryover writes recovery-worktree bytes without committing or staging. Equal interrupted document members are not rewritten; differing members stay review-required, and unrelated invalid onboarding forces whole-tree validation and rollback. The leaf writer supplies its own row without a memory commit, then ordinary closeout creates one attributed closed-history memory commit. Opt-in real-L47 witnesses require L56_REAL_PLAN_OUTPUT/L56_REAL_APPLY_OUTPUT; real apply asserts R27.2-new-record refusal for INV-EX6T0F and restoration, not successful real-data carryover. These stored assertions and source contracts are not fresh execution or independent acceptance.

The added source cases compare each delivered decisions/carriedPaths/reportPath field with the retained whole-result log for plan and apply, and check typed legacy-plan refusal for either unconverted side without memory writes. These are static assertion accounts, not new execution claims.
