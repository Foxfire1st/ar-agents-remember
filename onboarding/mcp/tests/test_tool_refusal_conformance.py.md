### Logic

**Four shapes, each named, and the partition is asserted.** A typed refusal has `ok: false`, a refusal identity, a non-empty reason and the navigation required by the response-owned path oracle. A stateful refusal has `ok: true` and `state: refused`. The other shapes are the four declared `ALWAYS_ANSWERS` and the ten declared `BARE_RAISERS`. `test_every_failure_path_answers_in_one_of_the_four_named_shapes` compares observed sets with their declarations in both directions.

**The population is derived at run time, never written as a count.**
`test_the_censused_population_is_the_advertised_one` (`:410-419`) asserts the live server's
`list_tools` equals `PUBLIC_TOOLS` and that the census drove exactly that set. The census's own
table lives in `tool_refusal_census_support.py::failure_invocations`, and `drive_census` refuses
a table that is not the roster before it drives anything.

**The three axes are asserted separately, by name.**
`test_every_refusal_names_what_refused_why_and_the_next_action` (`:462-493`) collects the tools
missing each axis and reports them by axis, so a refusal that stops naming *why* fails on that
axis rather than as a generic "refusal shape changed". `refusal_axes` (`:232-243`) reads the axes
from the payload itself; `ok` is deliberately not one of the three, because a payload that is not
a refusal at all should fail as *answered*, not as *refused without a reason*.

**The positive control and the predicate control.** The T34 case reads the imported `T34_REPAIRED_TOOLS` selection, currently `memory_baseline_adopt`, and requires each selected advertised tool to return a refusal with all three axes. `FailurePathControlTests` constructs a literal refusal-shaped dictionary and strips identity, reason and navigation in turn, requiring `refusal_axes` to detect each loss.

### Conventions

Plain pytest classes, with no `unittest` or module marker override. The module is registered in `unit-regression`. `FailurePathCensusTests.setup_class` builds one world and census; `teardown_class` closes it. The oracle and negative-control classes do not share that census fixture.

### Invariants And Boundaries

- **Hermeticity is asserted as a fixture property.** `test_the_module_runs_in_seconds_and_touches_no_real_state` requires fixture repository and memory roots inside the disposable root, the fixture coordination root and no providers.
- **The pin update rule is explicit.** A repair removes its entry in the same change; constants are neither deleted nor widened to hide a new failure.
- **Delivery shape is the boundary.** A refusal envelope does not prove that the tool made the correct product decision. The current bare-raiser population is the source’s ten-name declaration.
