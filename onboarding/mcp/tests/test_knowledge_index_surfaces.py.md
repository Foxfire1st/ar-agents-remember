## Purpose

Checks converted knowledge reads, report-backed knowledge comparisons, index integrity and explicit legacy-format refusals. The converted-tree read checks its cache filename through `KnowledgeIndexCache.path_for`, so the assertion follows the build-bound namespace.

## Code Commentary


The mounted diff assertions read the comparison from its report, not an inline patch body or `_diff_body`. At both forty long cards and nine hundred files, the ported threshold test uses `count_response_tokens` and `bound_for("knowledge_diff")`, asserts state `compared`, retains the full changed-file count and rejects an overflow/resultKept form. Every changed file is present in the report; one path narrows to its reported patch. Existing per-file patch caps and truncated flags remain report facts, not names of files left out of the answer. The integrity case uses its explicitly marked domain-unit `_check_body` result for unconditional root, validator and complete finding assertions. The mounted result checks the returned validation window when it fits. On overflow the test checks the cut status and derives the expected window from the domain-unit result.

A small comparison names both trees, counts, a bounded decision-record list and its total beside the report. A named record has a repository-relative `knowledge/invariants/` path; its statement and the changed realization rationale are inspected in the report rather than delivered inline. Omitting the after revision compares the working tree, writes loose objects and leaves refs, HEAD and the Git index unchanged in the source assertions. Selectors, legacy-format refusals, retired-record selection, partial indexes and unbuildable-index refusals remain.  These are inspected source assertions, not test execution or an unconditional CODE verdict.

### Logic

- **Retired records:** a retired invariant and its claim are not projected and not selected by a path read, while the index answers the record as `retired`; a retired family is not projected and is still answered with its members.
