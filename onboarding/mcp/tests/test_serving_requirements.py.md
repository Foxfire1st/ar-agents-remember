## Purpose

HTTP proofs for the confined task-local `requirements/` artifact root
(260831-CCR-L23), registered in the `integration` lane of
`test-evidence-lanes.toml`. It drives the two GET routes over a real
`TestClient` against a temporary coordination tree and asserts the exact
registered-packet listing/read semantics, absent-root behavior, traversal and
confinement refusals, context-mismatch refusals, inventory bounds, and the GET-only
posture.

## Code Commentary

### Logic

`RequirementRouteTests` builds, in `setUp`, a temp workspace + coordination
root with one master document (`tasks/R/260831_master`) and a second master for
the mismatch cases, then seeds a `requirements/` root with one Markdown packet, a
nested packet, and a non-Markdown file. `_client` creates the app with a test
McpRuntimeConfig; `_params` supplies the canonical selector; `_seed` writes
the fixture root.

- **list/read semantics** — the listing registers only exact Markdown packets (sorted
  `requirements/...` addresses, size + sha256 of the exact bytes); read returns
  exact content + canonical address.
- **absent and malformed** — an absent root is a valid empty unregistered listing; a
  missing packet and a Markdown-named directory are 404 not-found.
- **confinement** — traversal, absolute Windows/POSIX paths, empty and unsupported
  paths are 400 `bad-path`; symlinked roots, escaping children, and in-root
  aliases are refused on both list and read.
- **context** — wrong-master/ghost-document selectors are 400 `bad-context`,
  unknown repo 404; nested master, `../` documents, and Windows-slash documents
  are 400.
- **bounds** — depth > 8 and file-count overflow (patched
  `_MAX_INVENTORY_FILES`) fail closed with 400.
- **surface** — `POST` to the read route is 405.

### Conventions

Unittest + TestClient in the serving-suite idiom; confinement edge cases reuse
`confine_non_symlink_rel` directly (including a patched containment proof) to
pin the kernel guard, not just the HTTP mapping.

### Invariants And Boundaries

Every refusal is server-side and typed; no test asserts a client-visible filesystem
root; the symlink and containment cases prove the no-alias rule independently of the
HTTP error mapper.
