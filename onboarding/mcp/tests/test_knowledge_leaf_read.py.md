## Code Commentary


The source declares twelve unparametrized test functions. A path selects its registered entries, complete directly containing families and their members, while advertising a further family without recursively expanding it. The internal published-intent block retains applicability, conditions, exclusions, admission, realization roles and typed proofs; knowledge_read projects record kinds, IDs, roles, states and locations rather than returning that prose. Identity seeds retain the separate recorded-family-frontier scope policy. The internal published-intent block and knowledge_read bind the same selection manifest; this is not row equality or a read_ar_files document carrier.

The assertions cover named registration absence, a route chain without entries, partial indexes, a repository without a commit, bounded seed tails, derived titles, and continuation at the originally named code tree. Fixtures construct converted text documents and Git trees through knowledge_index_test_support. No projection writer or projection64-cap test remains here; the former thirteen-case/projection account is historical removed coverage. This card describes source assertions, not a collection or runtime verdict.

### Logic

- **The world.** `_invariant`, `_family`, `_sidecar` and `_graph` write a converted memory tree through the text-file layout (records, families, onboarding sidecars with `realizes` and `proves`); `_read` calls the public `knowledge_read_payload` boundary with the selected roots. The forty-long-member leaf-walk premise now asserts that the public name-only page fits the product bound, contains no repeated statement text and carries its continuation. `_read_body` supplies the rich domain-unit rows and next top-level continuation for the retained selection assertions; this is not pointer retrieval or proof of a retained whole-result artifact. Subsequent public calls and internal rows are kept distinct, including continued family/reference identity assertions. The module imports `knowledge_index_test_support` for the shared review fixtures and Git helpers.
- **Internal selection and order** (`test_a_path_selects_one_family_hop_in_the_declared_order`, through published_intent_block, not the read_ar_files naming answer). A three-family graph with a shared member, a retired member, a proof entry and an advertised family. It asserts the exact row sequence (rule 4), the header fields (rule 2), the member and entry fields (rule 3), the `member_reference` of `INV-CCCCCC` under `FAM-F22222` with `returnedUnder: FAM-F11111`, `title == "INV-CCCCCC holds."` and `titleDerivedFrom: "statement"` (rule 5, ruling Q1), one `advertised_family` row for `FAM-F33333` with `via == ["INV-CCCCCC", "INV-DDDDDD"]` (ruling N4), the exact `counts` (rule 8), `memoryTreeId` (rule 9), the current block's top-level `policyVersion == "family-complete-leaf/v2"`, and that a proof-only path also seeds the read (ruling Q3).
- **Both representations** (`test_both_surfaces_return_one_selection_under_one_manifest`): the internal published_intent_block and knowledge_read source_context share a manifest, selection policy and ordered record IDs. The test maps structural row kinds to projected kind/role pairs rather than asserting full-row equality. It asserts the named currentness invariant set and the reason that no code tree was requested.
- **Family names** (`test_the_invariant_view_names_its_families`): the invariant view names the three family IDs and excludes the fixture family title from its serialized answer.
- **The conforming example** (the historical test identifier `test_the_conforming_example_returns_the_whole_family_in_one_response` is retained): the knowledge_read page has no continuation, stays within the page threshold, includes both invariant IDs, and gives every row an admitted kind/state and an existing location file. The selected member carries neither statement nor guarantee; the assertion is not whole-family prose delivery.
- **MIK-R05 adaptations (L05).** The L01 fixture routes `FAM-F11111` at `src` and `FAM-F22222` at `.`, so the selection test's expected sequence gains two `chain_family` rows after `advertised_family`, `counts` gain `chainFamilies: 2`, and `rowsTotal`/`rowsReturned` go from 15 to 17; the policy assertions name `family-complete-leaf/v2` (ruling Q4, 2026-09-30 03:32:18). The internal selection assertions remain; L109 separately adapts the knowledge_read projection and continuation assertions described above.
- **An entry-less path under a route** (`test_a_path_without_entries_still_returns_its_route_chain`, MIK-R05): `src/nothing.py` is a page stating `registration: registration_absent` with the N6 wording and its two chain rows.
- **Failure states** (`test_absent_and_partial_states_are_named`): with `FAM-F22222` re-routed to `src`, `docs/nothing.md` has no entry and no governing family, so it is refused `registration_absent` on both surfaces, naming "realization or proof claim" (ruling N6), and both refusals carry the same `routeChain` stating `no_governing_family` (MIK-R05). The block's policy is `family-complete-leaf/v2` (N5), and a complete tree's refusal names the same memory tree as the block (ruling N3).
- **A partial index** (`test_a_partial_index_is_named_on_both_surfaces`): an ungoverned path read from a partial index states `indexState: partial` and `indexComplete: false` (ruling N3). This and the entry-less case were split out of the failure test by review R1 F1 (2026-09-30 04:12:49) so no adapted test is at radon C.
- **Carried obligations.**
  - `test_a_repository_root_with_no_commit_is_refused_by_name`: a repository with no commit, and a plain directory, are refused `selected_input_unavailable` naming the root (carried 2026-09-29 21:17:07).
  - `test_a_leaf_walk_resumes_at_its_code_tree_from_the_named_repository`: the token carries no local path, the walk resumes at page 1's tree from the workspace, and an unrelated root is refused by name.
  - `test_a_tail_longer_than_one_queue_is_refused_by_name_within_the_threshold`: 104 seeds at deep `_DEEP` paths give `seed_queue_exceeded` with `seedCount` and `firstSeed`, the block stays within 8,000 tokens and nothing raises (carried 2026-09-29 21:32:34).

- **The derived title** (`test_a_derived_reference_title_is_the_first_sentence_cut_to_a_fixed_length`): the first of two sentences, a decimal inside a sentence, no sentence end, and a 200-character sentence cut to exactly `DERIVED_TITLE_LENGTH` ending in `…`.
- **Identity seeds on a tree** (`test_identity_seeds_on_a_tree_keep_the_scope_read_beside_the_leaf`, ruling N2): a 30-member family read through `read_published_intent` with an identity seed, a path, then 29 more identity seeds. It covers a scope page in the block, each kind's collapsed tail (continuation views `invariant` and `source_context`), every continuation walked through `knowledge_read` (including `tree_read._scope_response` and the moves between queued seeds), every seed's rows exactly once against `select_knowledge_scope` and `select_leaf`, delivered fitting pages measured through `response_tokens` and overflow pages retaining `resultKept: false`, and the mixed-block policy: the top level keeps `recorded-family-frontier/v1`, and each page states its own `selectionPolicy`.
