# mcp/tests/test_review_limit_wording.py

## Governing Overview

[Test suite](overview.md)

## Purpose

Guard review-budget and stage-boundary wording in the explicitly scoped lifecycle sources and compiled role/operation text. Instruction sources name the settings limit rather than embedding its numeric value; required role facets belong inside the extracted stage-end section.

## Code Commentary

The number detector recognizes digit and generative number-word budget forms while exempting round labels and granted allowances. Source scans cover the named canonical, packaged and starter Markdown populations. Compiled checks use the declared package/canonical role-operation matrices; separate synchronization tests establish projection equivalence. Required Worker, Reviewer, Curator and Manager clauses are checked inside the extracted section, with source deletion/relocation and compiled deletion controls. Rule-nine checks bind the property-and-construction sentences to the specified roles and operations.

### Invariants And Boundaries

- This suite compiles instruction text and starts no role. It is not the real lint-repair sandbox/host evidence.
- Its detector controls establish the declared prohibited/exempt forms, not every possible paraphrase.
- It does not independently scan registered task_doc tool text, prove heading uniqueness, or compile every native harness launcher.
