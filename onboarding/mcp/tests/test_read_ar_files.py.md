## Code Commentary

The source-read cases check exact slices/full text, binary omission, path and symlink confinement, overview/route-chain deduplication, refresh/reset behavior and committed source selection. They remain source assertions; this curation does not call the read_ar_files tool.

PublishedIntentRouteTests constructs a converted memory tree with build_world, resolves its actual PublishedIntentSelection and calls the ordinary route with that context. It asserts source plus a complete derived tree index, named seed/registration refusals and actual carrier field spellings. It no longer substitutes a legacy selection through `_read`.

Removing the layout marker makes the root unusable/legacy-format with empty seeds. Mounted-route cases build a real coordination declaration and require legacy-format for an unconverted root, with source still returned. Historical direct canonical publication/database-isolation journeys were removed; no current database-selection coverage is claimed.
