[Route overview](overview.md)

## Purpose

The planned binding's one exact record — the master line and the four measured sides — with a master line that moves before any effect refusing the build, and the counts an Update answers.

## Code Commentary

- A master tip that moves between the comparison read and the preparation refuses the build and the Update before any effect; an unreadable master line refuses them by name.
- The written packet, grants, binding and snapshot all name the same four measured sides, so no artifact can disagree about what was prepared.
- A planned comparison binds the master line — an atomic master's integration branch, not its fork source — and the read, the Update and the moved watcher all follow that line; an organizational master binds its sprint integration line.
- A count that cannot be read is reported unavailable, never as a silent zero.
