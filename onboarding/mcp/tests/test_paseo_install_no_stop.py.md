## Purpose

The install no-stop cases: a live host is preserved after admission and at every irreversible site, a host appearing after a failed start reply is preserved, an unfinished live provider write names the owned terminal recovery, a non-UTF-8 harness failure keeps the earlier install result, the fake npm requires provision to supply each locked input, a replacement defers without a write, a live setting applies while a late restart-required answer defers, an unanswering supervisor is left alone, and a host on another Node defers before any change.

## Code Commentary

The module drives `provision_for_install`/`provision_runtime` with the late-restart and observation-failure fakes and the real provider-write rollback path.

The earlier-Node case also checks explicit provision: the replacement host starts once on the contract Node, its earlier sibling Node folder is reported as unused by that host with its marker retained, and a repeated provision changes nothing.
