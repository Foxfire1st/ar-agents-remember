## Purpose

The R71 role-choice cases: what a user's settings, a repository and the host each decide, and what a selection may not supply for itself.

## Code Commentary

`write_user_settings` changes only the tested family in the user's own file, because the host lives in the authority file. The cases pin host fields winning while each source stays recorded, an explicit safe mode that inherits neither the catalog default nor the user's policy, provider and model overrides that do not inherit a foreign permission choice, and an unoffered mode, feature or value refusing before a corrected selection succeeds. A start call cannot supply permission authority; a repository authority refusal covers both families with alias merge; a profile binds by exact name first and reports why one is unavailable. Plain-text overwrite blocks a raw digest and loads no file. Report collection survives removal without following a legacy alias and a failed collection preserves the source and the link target; a handover keeps its assignment and local paths when the baseline is replaced; the collection budget and non-leaf retirement preserve durable reports. Unknown modes refuse while fully listed empty modes stay distinct, unchanged file metadata is reused for two evidence sizes, and refusals name the exact settings and host profile sources. An observed mode and feature mismatch is warned publicly. Each role grant excludes a second configured AR server, completed cleanup collects before the same role folder is removed, the public reader carries no caller path or mutating operation, layer binding keeps one harness's auto apart from another's, per-level origins bind at the authored layer with their provider controls, collection cache churn reaches a bounded fixed point and retires, and a host custom provider needs no AR declaration.

## Invariants And Boundaries

A value the caller supplies is not an authority: the cases assert refusals wherever a start call tries to state a permission choice. Sources are recorded per level rather than collapsed, and a refusal names the file it came from.
