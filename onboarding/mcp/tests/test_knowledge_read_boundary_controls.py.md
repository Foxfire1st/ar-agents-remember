## Purpose

**MIK-R74 rule 6: independent oracle acceptance controls.** Split whole from `test_knowledge_read_boundary.py`: pure unit cases over hand-built world states plus real-Git witnesses, every assertion preserved and only the address changed. No product read runs here, so each control fails the oracle regardless of any read's success or refusal.

## Code Commentary

A real unauthorized object write fails; borrowed alternate objects answer to the same attribution; transitive alternate chains are followed and cycles terminate; the inside-root chain to an outside lender is inventoried (the F5 repair: pointers followed before the containment skip); an empty directory, an unattributed object, a nested Git admin dir each fail; refs are keyed by name so a shared object never collapses two refs; a moved pin is a finding while a both-halves-attested pin passes.
