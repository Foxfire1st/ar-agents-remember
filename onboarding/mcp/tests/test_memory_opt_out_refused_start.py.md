## Purpose

MIK-R50 rules 1-2: the start refuses the removed mode by name before anything exists, and nothing in the product produces it anymore. Route refusals on legacy contracts live in the companion routes module; the vocabulary itself lives in the mode-removal module.

## Code Commentary

Rule 1 pins the refusal before anything exists — no contract, branch, worktree, or task binding is created — with dry run and real run answering identically. Converted knowledge names the D5 mandate and where it was found; plain memory gives the removal reason instead; a repository Git cannot use names the probe failure; the `disabled-memory` choice answer and both module CLI options are refused by name with the same status; unknown choice tokens and unknown modes stay plain invalid requests and never borrow the opt-out status; a missing memory root keeps the existing missing-memory error while the genuinely setup-first shape names the setup action; and a master's first leaf is refused before the series contract can exist.

Rule 2 proves no producer is left: restarts after an abandoned or reopened disabled tombstone land external, a modeless start attaches to a live legacy leaf without admission preempting it, and cleanup of a terminal archived disabled contract answers the refusal rather than a developer decision. The remaining cases pin that reopen restart arguments carry no mode for legacy contracts, that a missing memory repository offers only the setup choice while answering `disabled-memory` is refused, and that the raised error and the published fields agree on the one status.
