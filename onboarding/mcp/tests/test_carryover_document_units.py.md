## Purpose

Define converted document-pair, regular-member/format admission, official-tree anchor and named-record dependency units.

## Code Commentary

Markdown and JSON travel as an indivisible onboarding document unit for file cards, route overviews, memory-only documents and entity catalogs. Records require JSON; Markdown companions are optional but, when present, participate in exact comparisons. Anchor observations use an official Git tree and do not mutate source bytes. Source history is reading aid only. Non-object layout roots and source/target layout FIFOs retain conversion/crossing guidance; the layout FIFO witness uses a subprocess with timeout=HANG_GUARD_SECONDS and no FIFO writer. The selected-member FIFO unit case directly calls safe_memory_path for document Markdown/JSON and invariant JSON/Markdown; it is not a public selected-FIFO plan/apply integration witness. Static lstat-before-read admission is not a race-proof descriptor claim. No execution, public closeout or acceptance is inferred.
