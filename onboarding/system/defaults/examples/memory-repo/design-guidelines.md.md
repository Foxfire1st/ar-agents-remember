# system/defaults/examples/memory-repo/design-guidelines.md

## Governing Overview

[Route overview](../overview.md)

## Purpose

The example design process, which holds no design values at all.

## Code Commentary

An example, shipped for guidance; a repository keeps its own in system/design-guidelines.md and nothing falls back to this copy. It says how design work is done and checked and where the design files are - and deliberately holds no colours, sizes, fonts or component looks.

## Boundaries

The obligation above is the whole of what this file must keep true; the route account says what the surrounding surface promises.

## Evidence

- Design work's process is described here and its values are not, so a repository cannot satisfy the process by inheriting this file [1]
